# Architecture Decision Records (ADR)

Registro de las decisiones de arquitectura de Finap. Cada ADR documenta el contexto, la decisión y sus consecuencias.

## Formato

Cada ADR usa esta estructura:

```
# ADR-NNNN: Título

- **Estado**: Propuesto | Aceptado | Reemplazado por ADR-XXXX
- **Fecha**: YYYY-MM-DD

## Contexto
## Decisión
## Consecuencias
```
