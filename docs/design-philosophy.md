# Faceta Cálida

Filosofía de diseño de Finap.

## El movimiento

La **Faceta Cálida** parte de una sola unidad geométrica —el rombo, la faceta— repetida y recortada con la precisión de un maestro tallador. El espacio no se decora: se talla. Cada superficie se resuelve en planos nítidos separados por aire generoso, donde la forma geométrica actúa como estructura y como adorno a la vez, colocada con una atención que delata incontables horas de refinamiento.

El color es el segundo material. Una gama cálida —rojo, naranja, ámbar— ancla la composición sobre neutros silenciosos. No es color que llene; es color que señala. Cada acento cromático está calibrado con paciencia para que una sola mancha de color ordene la mirada, en lugar de dispersarla. La paleta se comporta como una escala de valores: el calor se dosifica, nunca se derrama.

La tipografía es escultura. Pocos pesos, escalas amplias y deliberadas, con el titular usado como gesto visual activo, no como vehículo neutro. Las palabras aparecen solo cuando son imprescindibles, integradas en la arquitectura como un elemento más, trazadas con la sobriedad de quien domina el oficio.

La composición busca un equilibrio asimétrico: un único punto memorable rodeado de quietud disciplinada. Se prescinde de todo ornamento que no sirva a la idea. Lo que queda es el resultado de quitar, una y otra vez, hasta alcanzar una claridad que pareciera inevitable, fruto de un cuidado obsesivo por cada alineación, cada margen, cada respiración.

El resultado debe leerse como una pieza labrada a mano: meticulosamente elaborada, con atención dolorosa al detalle y una ejecución de nivel maestro. Nada es genérico, nada es casual; cada elemento existe porque fue elegido, medido y pulido hasta la perfección.
